│ Context                                                                      │
│                                                                              │
│ The feeds/nz_legislation_api/ directory currently has only a README and .env │
│  file. We need to build a simple Python API client that wraps the four       │
│ endpoints of the NZ Legislation API, plus provide example usage for          │
│ interactive testing.                                                         │
│                                                                              │
│ API Endpoints to Wrap                                                        │
│                                                                              │
│ 1. Search Works — GET /v0/works/ (search/filter legislation)                 │
│ 2. Get Versions of a Work — GET /v0/works/{work_id}/versions/                │
│ 3. Get Version Details — GET /v0/versions/{version_id}/                      │
│ 4. RSS Feed — GET /api/rss/works/{work_id}/versions/ (XML)                   │
│                                                                              │
│ Auth: api_key query param or X-Api-Key header. Rate limit: 10k/day, 2k per 5 │
│  min burst.                                                                  │
│                                                                              │
│ Project Structure                                                            │
│                                                                              │
│ feeds/nz_legislation_api/                                                    │
│ ├── .env                    # existing — API key + config                    │
│ ├── README.md               # existing                                       │
│ ├── pyproject.toml           # new — project metadata, httpx + python-dotenv │
│  deps                                                                        │
│ ├── nz_legislation/                                                          │
│ │   ├── __init__.py          # re-export client                              │
│ │   ├── client.py            # NZLegislationClient class                     │
│ │   └── models.py            # dataclasses for API responses                 │
│ └── examples/                                                                │
│     └── explore.py           # example script for interactive use            │
│                                                                              │
│                                                                              │
│ Implementation Steps                                                         │
│                                                                              │
│ 1. Create pyproject.toml                                                     │
│                                                                              │
│ - Project name: nz-legislation-api                                           │
│ - Dependencies: httpx, python-dotenv                                         │
│ - Python ≥ 3.10                                                              │
│                                                                              │
│ 2. Create nz_legislation/models.py                                           │
│                                                                              │
│ Dataclasses for typed responses:                                             │
│ - Work — id, title, type, status, year, etc.                                 │
│ - SearchResult — list of works + pagination info (total, page, per_page)     │
│ - Version — id, work_id, title, date, format links                           │
│ - VersionDetail — extended version info                                      │
│                                                                              │
│ 3. Create nz_legislation/client.py                                           │
│                                                                              │
│ NZLegislationClient class:                                                   │
│ - __init__(api_key, base_url) — loads from args or .env                      │
│ - Uses httpx.Client with X-Api-Key header                                    │
│ - search_works(search_term, search_field, legislation_type, page, per_page,  │
│ sort_by, ...) → SearchResult                                                 │
│ - get_versions(work_id, sort) → list[Version]                                │
│ - get_version(version_id) → VersionDetail                                    │
│ - get_rss_feed(work_id) → raw XML string                                     │
│ - Basic error handling (401, 404, 429)                                       │
│ - Context manager support (with statement)                                   │
│                                                                              │
│ 4. Create nz_legislation/__init__.py                                         │
│                                                                              │
│ Re-export NZLegislationClient and model classes.                             │
│                                                                              │
│ 5. Create examples/explore.py                                                │
│                                                                              │
│ A runnable script demonstrating:                                             │
│ - Loading client from .env                                                   │
│ - Searching for acts by title                                                │
│ - Listing versions of a work                                                 │
│ - Getting version details                                                    │
│ - Printing results readably                                                  │
