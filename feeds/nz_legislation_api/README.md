# An API client for the new NZ API  https://api.legislation.govt.nz

The API is available at https://api.legislation.govt.nz
API documentation is at https://api.legislation.govt.nz/docs/
Terms of use are available at https://pco.govt.nz/about-us/legislative-data-and-technology/api-terms-of-use


## Features

This is a simple API client that provides python classes representing all the available API operations.

It will be used initially to explore the legislation data and learn more about the domain.

### Background info from the API team lead Andrew Jacombs

Just to clarify what this API is: it provides a programmatic view to what is available on https://legislation.govt.nz, or technically what is available at https://demo.legislation.govt.nz, which is a preview of the new legislation website that will be becoming the main website in March. That site is managed by my team at the Parliamentary Counsel Office (PCO), whose main responsibility other than that site is the drafting of legislation. The Parliament website at https://www.parliament.nz/ is managed by Parliamentary Service, who are responsible more broadly for the running of Parliament, and which the PCO is separate from. I believe the Parliament web team are also working on some APIs you may be interested in, and that website has some stuff about legislation we don’t have, such as data about Bills showing their progress through the House.
