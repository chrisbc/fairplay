The Core Asymmetry

What consumers receive
  • → Infrastructure (while it functions)
  • → No consultation
  • → No affordability guarantee
  • → No exit mechanism
  • → No refund if asset strands
What bondholders receive
  • ↑ Statutory guaranteed revenue stream
  • ↑ 30-year fixed income
  • ↑ Forced sale powers if default
  • ↑ Zero exposure to asset performance
  • ↑ Levy continues even if asset is idle
